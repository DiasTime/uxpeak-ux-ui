# Тест: ревью карточки товара

[`product.html`](product.html) — мобильная карточка товара (горный мёд, 375 px), в которую
специально заложены 17 ошибок из видео uxpeak. Два независимых агента получили одинаковый запрос:

> Сделай UX/UI-ревью мобильной карточки товара нашего интернет-магазина мёда. Что не так и как
> исправить? Вёрстка в файле product.html (фото в hero — светлое, медовое; файла картинки нет,
> считай что оно светлое).

Первый агент работал со скиллом, второй без него, по своим знаниям.

## Результат

| | Со скиллом | Без скилла |
| :-- | :-: | :-: |
| Найдено заложенных ошибок | **17 из 17** | 16 из 17 |
| Объём ревью | ~900 слов | ~1 700 слов |
| Блок «главный вопрос экрана» | есть | нет |
| Блок «следующий уровень» | есть | нет |

Агент без скилла пропустил ошибку №2 и даже записал «1 кг» в названии в плюсы страницы. По
правилам uxpeak это вводит в заблуждение, когда количество выбирается отдельно.

Ответы целиком: [со скиллом](results/with-skill.md) · [без скилла](results/without-skill.md).

Это один тест, а не полноценный бенчмарк. Он показывает, что скилл работает и добавляет
правила, которых нет в общих знаниях модели.
