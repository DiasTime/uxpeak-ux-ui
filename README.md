## Что умеет

Скилл включается сам, когда разговор касается интерфейсов: ревью экрана, редизайн, карточка
товара, пейвол, онбординг, фильтры, поиск, нижняя навигация, конверсия. Вызывать его по имени не
нужно, хотя можно.

| Режим | Когда | Что получаешь |
| :-- | :-- | :-- |
| **Ревью** | Скриншот, макет Figma, вёрстка, живая страница | Находки по приоритету: критично → важно → полировка → следующий уровень. В каждой «что не так, почему, как исправить» с конкретными размерами и текстами |
| **Проектирование** | Новый экран, флоу или фронтенд-код | Порядок работы от ранжирования элементов до микровзаимодействий, конкретные числа: тап-зоны, размеры, контраст |
| **Выбор варианта** | «Какой из двух лучше?», A/B | Разбор, какой вопрос задаёт каждый вариант, сколько стоит взаимодействие, где больше доверия |

Скилл не заменяет скиллы визуального стиля (например, `design-taste-frontend`), а дополняет их:
те задают визуальное направление, этот отвечает за UX-решения.

## Установка

**Claude Code, для всех проектов**

```bash
git clone https://github.com/DiasTime/uxpeak-ux-ui.git ~/.claude/skills/uxpeak-ux-ui
```

Windows (PowerShell):

```powershell
git clone https://github.com/DiasTime/uxpeak-ux-ui.git "$env:USERPROFILE\.claude\skills\uxpeak-ux-ui"
```

**Только для одного проекта.** Склонируй в `.claude/skills/uxpeak-ux-ui` внутри репозитория проекта.

После установки скилл появится в списке доступных в новой сессии. Проверить можно командой
`/uxpeak-ux-ui`.

**UX rules from the uxpeak channel:** also load `uxpeak-ux-ui` together with the taste skill

## Как пользоваться

Просто опиши задачу:

```text
Сделай UX/UI-ревью этого экрана [скриншот]
```

```text
Какой пейвол лучше, A или B? [два скриншота]
```

```text
Спроектируй фильтры для каталога квартир: цена, комнаты, район, этаж
```

```text
Сверстай карточку товара для интернет-магазина фермерских продуктов
```

## 12 главных идей

1. **Каждый элемент задаёт пользователю вопрос.** Делай вопрос лёгким: «можно попробовать
   бесплатно?» вместо «стоит ли это $19 в месяц?».
2. **Сначала ранжируй, потом рисуй.** Если ты не можешь сказать, что читается первым,
   пользователь тоже не сможет.
3. **Показывай, а не прячь.** Каждый лишний тап, дропдаун или баннер — это стоимость
   взаимодействия.
4. **Отвечай на вопросы до того, как их зададут.** Итог в кнопке, число результатов в кнопке
   фильтра, «бесплатная отмена до…».
5. **Конкретность — это доверие.** «4,9 ★ · 221 отзыв», «старт в 2 касания», одна цена вместо
   диапазона.
6. **Проектируй систему, а не один экран.** Иконки читаются на любом фото, карточка выглядит
   одинаково при любых данных.
7. **Выглядит проще ≠ решать проще.** Фильтры на отдельных страницах выглядят чисто, но решение
   разорвано.
8. **Встречай людей там, где они сейчас.** Новичку простое начало, постоянному его план,
   продвинутому статистика.
9. **Работай с психологией решений.** Дефолты, прогресс не с нуля, ценность до регистрации,
   якорь цены. И честно: только реальные цифры и сроки.
10. **Последовательность.** Одно семейство шрифтов, один стиль иконок, одна сетка, один радиус.
11. **Обратная связь на каждое действие.** Выбранное состояние отличается двумя признаками,
    анимации добавляются последними.
12. **Учись у выпущенных продуктов и тестируй.** Реальные экраны, а не только Dribbble; тест,
    оптимизация, снова тест.

Полная шпаргалка «делай / не делай» по шести темам — в [SKILL.md](SKILL.md).

## Проверка

Мобильная карточка товара с 17 специально заложенными ошибками и одинаковый запрос двум
независимым агентам:

| | Со скиллом | Без скилла |
| :-- | :-: | :-: |
| Найдено заложенных ошибок | **17 из 17** | 16 из 17 |
| Объём ревью | ~900 слов | ~1 700 слов |

Без скилла агент пропустил «1 кг» в названии товара при выбираемом количестве и даже записал это
в плюсы. Подробности, страница и оба ответа: [evals/product-page-review](evals/product-page-review/README.md).

## Как собран скилл

```
yt-dlp: список видео  →  аудио 23 роликов  →  whisper.cpp (small.en)  →  ручной разбор  →  SKILL.md + 6 справочников
```

- Обработаны вся вкладка «Видео» (22 ролика, 2023–2026) и шортс. Шортс оказался без речи.
- Около 5,5 часов аудио распознано локально, правила выписаны вручную из каждого видео.
- Рекламные вставки (курсы, плейбук, спонсор) в правила не включены.
- В скилл попало то, что автор говорит вслух. Что показано только на экране, могло не попасть.
- Цифры вроде «конверсия выросла с 2 % до 7 %» — примеры канала, а не гарантии. В скилле это
  оговорено.

Таблица всех видео с датами: [references/sources.md](references/sources.md).

## Правовая оговорка

Неофициальный проект, не связан с uxpeak. Правила пересказаны своими словами по открытым видео
канала; расшифровки и фрагменты видео в репозиторий не входят. Права на видео и исходные
материалы принадлежат их авторам. Если правила пригодились, смотри оригиналы:
[youtube.com/@uxpeak](https://www.youtube.com/@uxpeak) и [uxpeak.com](https://www.uxpeak.com).
